# CheckMac — releases and support

[CheckMac](https://checkmac.app) is a native macOS disk-space analyzer. Point it
at a folder or volume and it shows where the space went.

This repository is where CheckMac releases are announced and where problems
are reported. To hear when CheckMac is released, click **Watch → Custom →
Releases** at the top of this page.

## Downloads

**CheckMac isn't available yet.** Releases will be published at
[checkmac.app](https://checkmac.app) and listed under [Releases](../../releases)
as signed and notarized disk images.

CheckMac requires macOS Sonoma 14 or later.

## What CheckMac does

- Sunburst and treemap maps of any folder or volume
- A sortable, searchable file browser
- A Discard Pile for reviewing cleanup candidates before anything moves to the Trash
- Saved scan snapshots you can reopen later

Scanning, browsing and the Discard Pile are free. A license unlocks moving
items to the Trash and comparing scans over time.

## Privacy

CheckMac has no account, no analytics and no telemetry. Scans stay on your Mac,
and license keys are checked offline. The only network request is an optional
update check. See the [privacy policy](https://checkmac.app/privacy.html).

## Reporting a problem

Open an [issue](../../issues) with your macOS version and the CheckMac version
from **CheckMac → About CheckMac**. Issues are public, so for orders, license
keys or anything private, email **support@checkmac.app** instead.
